# dsc106proj2

DSC 106 Project 2: Persuasive or Deceptive Visualization, on U.S. life expectancy since 1980.

- `index.html`: the report page (proposition, both charts, design rationale, reflection)
- `life_expectancy_support.png`, `life_expectancy_oppose.png`: the FOR and AGAINST charts
- `full-picture.js`: the interactive "Full Picture" chart (D3)
- `make_charts.py`: regenerates both PNGs from `data/us_life_expectancy.csv` (`python3 make_charts.py`)
- `data/us_life_expectancy.csv`: World Bank WDI `SP.DYN.LE00.IN`, United States, 1980–2024
